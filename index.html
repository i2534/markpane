ℹ️ 关于 Markpane

纯前端的文档渲染器：把 Markdown（以及 docx / pdf / pptx / xlsx 等）拖进浏览器就能读，可安装为 PWA、被系统关联为 .md 的默认打开方式。

快捷键

  • Ctrl+O 打开文件
  • Ctrl+S 导出 HTML
  • Ctrl+D 切换暗黑模式
  • Ctrl+L 切换同步滚动
  • Ctrl+\ 切换布局
  • ? 显示/隐藏本面板 · Esc 关闭
  • Enter 搜索下一项 / Shift+Enter 上一项

项目地址

  • 在线使用（GitHub Pages）：i2534.github.io/markpane
  • 源码仓库：github.com/i2534/markpane
  • 问题反馈：Issues

其他

  • 隐私：文件全部在浏览器本地处理，不上传服务器
  • 依赖：marked 18.0.6 · highlight.js 11.11.1 · KaTeX 0.18.1 · Mermaid 11.16.0 · DOMPurify 3.4.12 · AnyDoc (WASM)
